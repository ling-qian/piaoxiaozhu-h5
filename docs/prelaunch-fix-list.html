4. 平台后台动作（mp 后台，非代码）

  1. 类目选择：个人主体只能选工具类目，建议「工具 > 效率」。规避用词：小程序名称、简介、页面文案中避免出现「记账 / 财税 / 报销 / 税务」等可能被判为金融类的表述，统一定位为「票据识别与整理工具」。
  2. 避免「AI 生成内容」表述：个人主体无法通过深度合成 / AI 生成类相关审核。产品里 LLM 只做分类抽取，对外描述为「识别 / 整理」即可，不要写成「AI 生成报表文案」。
  3. 服务器域名：把后端 HTTPS 域名加入 request 合法域名；该域名须已 ICP 备案（云托管默认域名不能配到这里，官方明确其仅限测试）。
  4. 用户隐私保护指引 + 客服配置：与代码侧 privacy 页面逐条对齐。
  5. 个人主体做不了、不要规划：微信支付、手机号快速验证组件、web-view 加载外链、流量主广告。
